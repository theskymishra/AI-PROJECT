# Phase 14 Final Demo Runbook

1. Start the backend with one worker.
2. Start the Vite frontend.
3. Open the Dashboard.
4. Show the Disaster Map and select a scenario.
5. Demonstrate AI Routing and Risk Analysis.
6. Show AI Reasoning, Resources and Planning.
7. Show Evidence Fusion.
8. Prepare/execute the HTN plan.
9. Open Response Monitoring.
10. Open AI Explainability.
11. Open Response Evaluation.
12. Open **Final Report**.
13. Point out the Phase 1–14 integration list, simulation inventory and verification checks.
14. Optionally repeat the final report after changing the scenario to demonstrate that it is live and read-only.

The final report should be described as a project verification surface, not as an operational emergency-management tool.
