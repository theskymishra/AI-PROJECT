# Phase 11 Findings

## Objective

Add a transparent monitoring layer after HTN execution so the academic system can explain whether active emergencies remain assigned, whether resources are strained, and whether a fresh HTN plan can be generated.

## Findings represented by the UI

1. Active emergency count and assignment coverage.
2. Available/total ambulance capacity.
3. Available/total hospital beds.
4. Missing or invalid resource assignments.
5. Hospital capacity warnings.
6. Current HTN replanning readiness.

## Safety / scope

This is a deterministic simulation feature for an academic project. It is not an operational emergency-management system and does not issue real-world dispatch commands.
